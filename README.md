## About Me

Hi, I'm **Prayush Shrestha**, a BSc (Hons) Computing student and aspiring software developer based in Kathmandu, Nepal.

I enjoy building practical applications, exploring artificial intelligence, working with data, and developing solutions that turn ideas into functional software.

My interests span across software development, AI/ML, data analytics, data engineering, and cloud technologies.

- Experimenting with Godot and 2D/3D game development.
